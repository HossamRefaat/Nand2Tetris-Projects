# JackOS

Operating System library for the Jack programming language, providing essential system services and utilities.

## Overview

JackOS is a collection of standard library classes that provide core functionality for Jack programs, including memory management, I/O operations, mathematical functions, and string manipulation.

## Components

- **Array.jack** - Array allocation and management
- **Keyboard.jack** - Keyboard input handling
- **Math.jack** - Mathematical operations (multiply, divide, square root)
- **Memory.jack** - Memory allocation and deallocation
- **Output.jack** - Text output and display functions
- **Screen.jack** - Graphics and screen drawing operations
- **String.jack** - String manipulation and operations
- **Sys.jack** - System initialization and control functions

## Usage

These classes are part of the Jack standard library and are automatically available to all Jack programs. The `Sys.init()` function initializes all OS components and should be called at the start of any Jack program.
